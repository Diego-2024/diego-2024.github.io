## 在 GitHub 发布

1. 登录 `Diego-2024`，检查是否已有 `diego-2024.github.io` 仓库。有的话先保留原有内容，不要覆盖。
2. 如没有，创建名为 **diego-2024.github.io** 的 **Public** 仓库。
3. 将 `index.html`、`style.css`、`.nojekyll` 放在 `main` 分支根目录，不要再套一层文件夹。可同时上传本 README。
4. 打开 **Settings → Pages → Build and deployment**。
5. Source 选择 **Deploy from a branch**；Branch 选择 **main** 和 **/ (root)**，点击 **Save**。
6. 等待 GitHub Pages 部署成功，访问 `https://diego-2024.github.io/`，确认姓名、学校和邮箱正确显示。
7. 页面实际可公开访问后，将该网址填入 OpenReview 的 Homepage 字段。

本地文件和 ZIP 准备完成不代表已发布；最终以 GitHub Pages 构建结果与公开网址核验为准。
